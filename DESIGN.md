# DESIGN

I would like to create a custom dashboard for my Bridge-Thing-ified Spotify Car Thing.

The guide for publishing apps for BridgeThing is here: https://bridgething.com/docs/publishing-apps/

The GitHub Repository for BridgeThing is here: https://github.com/JoeyEamigh/bridgething

The dashboard should be customizeable through the BridgeThing Desktop app.

I would like it to support weather, with a location lookup feature.
I would like it to have a clock, with different face available, such as fuzzy, binary, analog, digital, and pixel.
I would like it to fetch the currently playing song from `https://display.soundtrackyourbrand.com/BEEPLE. This will need to refresh every few seconds.
I would like it to support playback control for the tethered device, with an option to show that widget at all times, or just when something is playing.

The visual design of the dashboard should be reminiscient of apple's liquid glass.
